# Cara Penggunaan
Aplikasi ini menggunakan flask sebagai UI, dan .json sebagai Knowledge Base sementara.
Cara penggunaan :
1. Server Side :
   a. Pastikan Dependency sudah ada :
	   a. Python
	   b. Flask 
	b. Jika perangkat Windows gunakan :
		cd  ArduSatoru 
		python ArduSatoru.py
		
2. Client Side 
	1. User bisa memasukan Domisili atau Harga atau Waktu tempuh ke dalam form untuk mendapatkan rekomendasi
	2. User kemudian dapat menambahkan juga tempat pariwisata
